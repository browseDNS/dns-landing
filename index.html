BrowseDNS is a public DNS server enabling Internet access for limited devices.

Terms of Use

BrowseDNS is a public DNS server that enables devices with hidden or limited built-in web browsers to browse the open Internet.

For a full list of supported devices, see here. We hold the view that access the Internet is an essential right, regardless of the device type that is being used.

Frequently Asked Questions

How does it work?

The DNS server utilizes the Captive Portal functionality built into modern devices. It redirects connection tests to this landing page, where you can reach the open Internet.

Why can't I play videos?

Video playback is explicitly disabled in some connection applets. We have no control over this hardware-level restriction. For the Switch, you can sign the petition at: fortheusers.org/change

How to disable?

If you'd like to stop using the service, simply set your DNS settings back to Automatic, or manually enter 8.8.8.8 (Google DNS).

To prevent access to the browser, set up system Parental Controls in your device settings. This will lock the network settings and prevent the DNS from being changed.
